## Слайд 6. Техника

**Время:** 3:10–4:10 · заголовок слайда = вывод

### На слайде

**Агент сам запрашивает данные о компании, когда это нужно, разбирает его и показывает готовый ответ в чате**

**Архитектура**

```
Веб-интерфейс (чат + панель)
        ↓
Агент-оркестратор (LangChain + память сессии)
        ↓ streamable HTTP
MCP-сервер verification_mcp_server
  → отчет в JSON-формате
  → Structured output
        ↓
Qwen 3.8 27B → валидатор ответа → ответ в UI
```

**Инструмент MCP-cервера ищет и передает агенту данные по компании, составляет матрицу для сравнения.**

### Визуал

Схема из 5 блоков: чат → бэкенд → данные по ИНН из MCP → языковая модель → бэкенд → чат

### Примечание спикеру

Если спросят про демо: агент на  принимает результат работы MCP-сервера и отвечает за формулировку и структуру данных.
